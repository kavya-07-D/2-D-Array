# 2-D-Array
Java implementations of 2D array and matrix problems, covering traversals, transformations, and grid-based algorithms.

A dedicated repository for practicing 2-D array data structures, matrix manipulations, and grid-based algorithmic problem solutions in Java.

## 📚 Topics Covered
* Matrix Initialization & Traversal (Row-wise and Column-wise)
* Searching in a 2D Matrix
* Matrix Transformations (Transpose, Rotation by 90 degrees)
* Boundary Traversals and Spiral Matrix
* Prefix Sum in 2D Arrays
* Grid-based Algorithms (e.g., Flood Fill, Island counting)

## 🛠️️ Tech Stack
* Java
